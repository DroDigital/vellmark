The newest Showcase build from `main`, for the owner. This release is a **draft**: only people with push access to the repository can see it, and nothing here is public until it is published.

Every build carries the development tools (the F keys and the console; press ` and type `help`).

### macOS (Apple Silicon and Intel)
1. Download `vellmark-macos-*.zip` and unzip it.
2. Right-click `Vellmark.app` and choose **Open**, then **Open** again. macOS asks once, because the build is not signed by Apple.
3. To start in the valley, right-click `valley.command` and choose **Open**.

### Windows
1. Download `vellmark-windows-*.zip` and extract it (right-click, **Extract All**).
2. Double-click `Vellmark.exe`, or `Valley.bat` to start in the valley. If SmartScreen warns, choose **More info**, then **Run anyway**.

### Linux
1. Download `vellmark-linux-*.tar.gz` and unpack it: `tar -xzf vellmark-linux-*.tar.gz`
2. Run `Vellmark/vellmark`, or `Vellmark/valley.sh` to start in the valley. It needs Vulkan drivers.

Keys: W A S D and the mouse to move and look, R (hold) to read close up, Escape for the menu, Tab for the pack, C (hold) for favourites, F6 for the close-up looks (fn + F6 on a Mac).
