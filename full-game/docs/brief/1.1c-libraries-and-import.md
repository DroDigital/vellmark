**Texture compression.** The bake needs one offline encoder that writes BC7 for Windows and Linux and ASTC for macOS, so texture packs differ by platform. No encoder is approved yet. In Phase 03, compare the maintained, permissively licensed options, confirm their current state, and record the choice in `docs/DECISIONS.md` before adding it as a bake-only dependency. The game itself only uploads the compressed blocks.

**Fracture.** Pre-fracturing breakable props is written in the bake tool using `glam` and `meshopt`. Do not add a destruction library.

Keep engine-integration features turned off, such as `rerecast`'s optional Bevy support. These libraries may depend on different `glam` versions, so convert at module boundaries and do not fork them. Run `cargo-deny` in CI so that any new dependency with a disallowed license fails the build.

### Import pipeline

The `bake` tool turns all source content into Vellmark's formats:

1. Prefer each pack's glTF release. Convert FBX-only sources once with a scripted Blender step, and treat the resulting glTF as the pinned input, so that CI and the bake never need Blender. Normalize scale to metres and orientation.
2. Retarget humanoids to the one skeleton. Remove materials, and assign each surface a material class with a glyph family.
3. Generate surface anchors. Use upright, world-aligned grids for architecture, and rest-pose anchors for skinned meshes.
4. Generate collision, navigation data, near forms, and exaggerated far forms.
5. Prepare textures as material maps and as per-cell glyph data.
6. Normalize, trim, and encode audio.

**Make it Vellmark's own.** Packs like these are widely used, and players recognize asset flips by their shapes. Combine parts into new buildings and creatures, change proportions, and use shared materials, the colour grade, and the fine print to unify everything. Every named boss, hero NPC, capital landmark, and Canonical item must have a silhouette that does not match any stock model.
