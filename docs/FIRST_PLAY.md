# A stranger's first play

For the owner, to run with someone who has never seen Vellmark. It tests the Showcase
Gate's line: **a stranger given the build and no instructions casts a word within three
minutes and reads something within five.** It also tests whether the game is fun to
someone who owes it nothing.

The game collects nothing. Everything here is written down by you, as you watch.

## Before they sit down

- [ ] A release build from the latest `main`, on the machine they will use, with the
      settings reset (delete `settings.ron` and the save, or start from a fresh install).
- [ ] Sound on, headphones if the room is noisy.
- [ ] A mouse and keyboard, or a controller, whichever they would choose at home. Ask.
- [ ] A watch or a phone stopwatch, and this page printed or open on another screen.
- [ ] Nothing about the game said beforehand: not the letters, not the words, not that
      surfaces can be read. "It's a fantasy game I'm making. Play it however you like."

## While they play

Say nothing unless they are stuck for more than two minutes, and then only "What are
you trying to do?" Write down every time they ask a question, and the question.

Start the watch when the title screen first answers a button.

| Moment | Time | Notes |
|---|---|---|
| First moves the view | | |
| First swings the weapon | | |
| First writes a word (casts) | | Within 3:00? |
| First reads something (holds Read, or presses it) | | Within 5:00? |
| First notices letters on a surface without being told | | What did they say? |
| First learns a word at a Standing Page | | |
| First fight won | | |
| First death, and how | | |
| First opens the pack | | |
| First trade | | |
| First time they laugh, swear, or lean in | | At what? |
| First time they look bored or lost | | Where were they? |
| Stops of their own accord | | |

Also note:

- Every prompt or line of text they read aloud, and any they misread.
- Any place they could not tell where to go.
- Any frame that hitched, any sound that was too loud or missing, anything that broke.
- What they did that you did not expect.

## Afterwards

Ask these in this order, and write the answers in their words. Do not explain anything
until all of them are answered.

1. What is this game?
2. What did you do in it?
3. What was the best moment?
4. What was the worst moment?
5. When did you first notice the letters? What did you think they were?
6. What does writing a word do? Which word did you like most?
7. Was there anything you wanted to do and could not?
8. Did the fighting feel good? What would you change?
9. Was anything hard to read, see, or hear?
10. Would you play more? Would you tell someone about it, and what would you say?

Then, only now, show them close reading at arm's length if they never found it, and
write down what they say.

## What to do with it

Paste each session into `docs/DEMO_FEEDBACK.md` under a dated heading, with the table,
the notes, and the answers. A Claude Code session then sorts it into what to fix, what
to tune, and what to leave, and fixes the first list (S07-T10).

The gate's line passes when at least three strangers in a row cast within three minutes
and read within five, with no hint given.
