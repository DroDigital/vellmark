# Feedback from strangers

What strangers said and did, pasted in by the owner. Nothing is collected by the game;
this file is the only record. Each session goes under a dated heading, newest first, as
`docs/FIRST_PLAY.md` sets out. Names are left out: "Player 1", "Player 2".

Sorted findings live under each session as three lists: **Fix**, **Tune**, and **Leave**,
written by the session that reads them, with the commit that fixed each one.
