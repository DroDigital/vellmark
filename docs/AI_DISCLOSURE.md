# AI disclosure

Every use of generative AI that reaches players, kept for Steam's content survey and
for itch.io's AI tag. Vellmark uses no AI generation while the game is running: nothing
is generated by a model on the player's machine or fetched from one.

## Code

The game's code, shaders, and tools are written by Claude Code (Anthropic) under the
owner's direction. That includes code that makes things when it runs or when the game
is baked, listed under Assets and Music below.

## Music

The score is composed as the game plays by code Claude Code wrote
(`crates/audio/src/score.rs`): a sequencer that plays phrases of the Vale's theme in D
Dorian, over chords it chooses, and rests. The theme is the motifs of four words played
in turn; the motifs are on the word sheets (`assets/data/words/`), written by Claude
Code to the brief's rules. Every instrument is synthesized by that code. No recording,
sample, or model-generated audio is used.

## Sounds

Every sound effect (word motifs, blows, footsteps, the ambience of wind, rain, water,
leaves, and birds) is synthesized at run time by code Claude Code wrote
(`crates/audio/`). No recording or model-generated audio is used.

## Assets

None from a generative model. Material maps (masonry, timber, earth, grass, bark, ink,
and the rest) are generated by the bake from noise functions Claude Code wrote, which is
ordinary procedural generation. The valley's terrain, trees, and the first-person kit
are built by code and data Claude Code wrote. The two typefaces are human-made and
licensed under the SIL Open Font License. No AI-generated model, texture, sound, or image
is in the repository, and none may enter a pack without passing the AI gate in
`full-game/docs/brief/1.1a-licenses-and-ai-gate.md` and the owner's sign-off.

## Voices

Every spoken line is murmured: wordless speech synthesized at run time by code Claude Code
wrote (`crates/audio/src/murmur.rs`), shaped by the cast file's presets. No voice model is
used for it.
