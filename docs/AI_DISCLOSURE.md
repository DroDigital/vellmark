# AI disclosure

Every use of generative AI that reaches players, kept for Steam's content survey and
for itch.io's AI tag. Vellmark uses no AI generation while the game is running.

## Code

The game's code is written by Claude Code (Anthropic) under the owner's direction.

## Text

| Text | Where | How it was made |
|---|---|---|
| System messages: the window title and the messages shown when the game cannot start | `assets/text/en/system.ron` | Written by Claude Code |

The canon, the script, and the voice lines in `full-game/docs/` are listed here when the
Showcase first ships text taken from them or written to them.

## Assets

None. The two typefaces are human-made and licensed under the SIL Open Font License.
No AI-generated model, texture, sound, or image is in the repository, and none may enter
a pack without passing the AI gate in
`full-game/docs/brief/1.1a-licenses-and-ai-gate.md` and the owner's sign-off.
